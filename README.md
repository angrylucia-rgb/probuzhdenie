# Космолябия · Атлас пробуждения

Интерактивный сайт: путь сквозь 12 станций — от Абсолюта через Землю и Человека к квантовому вакууму — с погружением в слои каждой станции, главами (Космический календарь, Древо жизни, Нить мысли, Лестница измерений, Биосфера) и «Изнанкой».

Сайт: https://probuzhdenie-pied.vercel.app (английская версия — `/en/`).

## Структура репозитория
- `dist/` — готовый статичный сайт; эту папку публикует Vercel (Root Directory = `dist`).
  - `index.html`, `en/index.html` — страницы (стили, разметка и весь код внутри, CSP по хешу скрипта);
  - `art/img`, `bsc`, `mbg`, `pano`, `strata`, `film`, `refimg`, `data` — картинки, видео и данные; адреса вида `v/<хеш>/…` кэшируются на год;
  - `vendor/` — three.js r128 и постобработка; `fonts/` — свои шрифты; `og/` — превью ссылки и иконка;
  - `vercel.json` — заголовки безопасности, кэш, rewrite `/v/<хеш>/…`.
- `src/` — исходники и сборка (см. ниже).
- `tests/` — автотесты собранного сайта.
- `package.json` — зависимости для перевода и тестов (`npm install`).

## Исходник: `src/modules/` (с v182)
Раньше весь сайт был одним файлом `base.html` на 20 тысяч строк. Теперь он разрезан на 69 файлов по разделам.
Файлы склеиваются подряд, в порядке имён, обратно в `base.html` — это делает сборка.
Это не ES-модули: все `.js` — части одного скрипта с общими переменными, как и раньше.

| Номера | Что внутри |
|---|---|
| `000–022` | заголовок, стили (`010–014-css-*.css`), разметка, шаблон «Правовой информации», загрузчик |
| `100–113` | запуск, данные кольца, общие функции, рендерер, частицы, силуэт, данные анатомии (`113-data-anatomy.js` — встроенные текстуры) |
| `120–135` | анатомия, Солнечная система и погружение в Солнце, Луна и Юпитер, ветки слоёв |
| `140–161` | «Сон и сознание», общая сцена, 12 станций (Ланиакея, фигуры Хладни и др.) |
| `170–191` | фон и астролябия, микромир, Земля, Абсолют, Чёрная дыра, Изнанка (`185`), постобработка, музыка |
| `200–212` | интерфейс, журнал, условия, язык и меню, сквозной путь по слоям, переходы |
| `220–261` | Космический календарь, Древо жизни, Нить мысли, маршруты, поиск, «Глубокий космос» (`255` — полёты, свет из прошлого, звезда рождения; `256` — «Атлас чудес»), Компас пути, Моя астролябия, Лестница измерений |
| `269–276` | Биосфера: данные, рисунки существ (`269`), механизмы, основы, панорамы, фильм, сама глава |
| `280–292` | Справочник, движение по кольцу, цикл кадров, адреса мест (`#/…`) |

Правила:
- Правка — только в `src/modules/*`. `base.html` производный, в репозиторий не входит.
  Если `base.html` поправить вручную, сборка остановится, чтобы правка не потерялась.
- Найти, где лежит фрагмент: `python3 modules.py where "текст"`.
- Новый раздел — новый файл с номером между соседями (например, `255-…js`).
- Новый встроенный `<script>` и атрибуты `onclick` не работают: CSP разрешает только основной скрипт по хешу.

## Сборка
```bash
npm install                       # acorn, acorn-walk (перевод), playwright (тесты)
cd src
python3 build3.py                 # артефакт: astrolabia.html + astrolabia_en.html (+ preview*.html с отладочными хуками)
DIST=../dist python3 build3.py    # сайт: dist/index.html, dist/en/index.html, legal/, robots.txt, sitemap.xml
```
- `ORIGIN` в `build3.py` — адрес сайта (canonical, hreflang, sitemap). При покупке домена поменять только его.
- `OWNER` и `MAIL` в `build3.py` — правообладатель и адрес для обращений.
- `head.txt`, `i18n/head_en.txt` — шапки страниц сайта (описание, og:image, canonical).
- Рисунки существ: `art/cut_bg.py` (вырезать фон), затем `art/make_art2.py` → `dist/art/img/<код>.webp`, маска в `data/bio.json`, запись `BIO_ART` в `modules/269-data-bio-masks-art.js`.

## Английская версия (`src/i18n/`)
Собирается из того же исходника, без второй копии кода.
1. `en_patch.json` — структурные правки кода: множественные числа, десятичная точка, `en-US`.
2. `extract.js` (Node + acorn) находит все строки с кириллицей: JS-строки и шаблоны, текст и атрибуты HTML.
3. `en.json` — словарь «русская фраза → перевод». `build_en.py` подставляет переводы и пишет в `missing.json` всё, что ещё не переведено.

**Ключи — фразы, а не куски разметки (с v182).** В JS-шаблонах текст перемешан с тегами. Раньше ключом был весь кусок шаблона вместе с тегами, и правка соседнего тега ломала перевод.
- Теперь `runs.js` выделяет из такого куска фразы:
  - текст между структурными тегами (строчные `<b>`, `<i>`, `<a>`, `<br>` фразу не рвут);
  - значения `title`, `aria-label`, `alt`, `placeholder`.
  Ключ — сама фраза.
- Классы, теги и вёрстку вокруг можно менять свободно. Новый перевод нужен, только когда меняется русский текст.
- Где одна и та же фраза переводится по-разному в зависимости от контекста, остаются ключи-фрагменты целиком (их около 50). Они проверяются первыми, а если не совпали, перевод идёт по фразам.

Новый русский текст:
```bash
cd src && python3 modules.py build && cd i18n
node extract.js && node todo.js '*' 20000 > list.txt   # непереведённые фразы с номерами
# перевод: файл «номер<TAB>перевод» → python3 merge.py пачка.txt
```

## Тесты (`tests/`)
```bash
node tests/run.js                  # все: файлы сборки, загрузка RU/EN, адреса и «Назад», меню слоёв, «Назад» в главах, полёт Земля ↔ Луна, «Глубокий космос», «Атлас чудес», сбой WebGL, телефон
node tests/run.js smoke nav-hash   # выбранные
```
- Тесты поднимают свой сервер `tests/server.py` (порт 8790), который отдаёт `dist/` с теми же заголовками, что Vercel.
- Графика в тестах программная (SwiftShader), поэтому прогон медленный: около 3 минут.
- Перед каждым пушем: собрать `dist` и прогнать тесты. Любой FAIL — повод не пушить.
