# Пробуждение · Астролябия сознания

Интерактивный сайт: путь сквозь 12 станций — от Абсолюта через Землю и Человека к квантовому вакууму — с погружением вглубь слоёв каждой станции, ответвлением к чёрной дыре в центре Галактики и второй частью сайта — «Изнанкой».

## Структура
- `dist/` — готовый сайт (статичный). Именно эта папка публикуется на Vercel (Root Directory = `dist`).
  - `index.html` — вся страница (сцены, тексты, встроенные изображения, Изнанка);
  - `vendor/` — three.js r128 и постобработка (свои копии, без внешних CDN);
  - `vercel.json` — кэширование библиотек.
- `src/` — исходники и сборка.
  - `template2.html` — шаблон страницы (стили, интерфейс, движок пути);
  - `micro.js` — микромир человека; `earth.js`, `e2.js`–`e5.js` — погружение в Землю; `abs.js` — слои Абсолюта; `refs.js`, `anat.js` — анатомия;
  - `solar.js` — Солнечная система; `sun.js` — погружение в Солнце (12 слоёв, ядерный синтез);
  - `bh.js` — чёрная дыра Стрелец A* (трассировка лучей по Шварцшильду) и тексты её ветки;
  - `iznanka/` — исходники «Изнанки» v3 (ES-модули), `iz_main.js` — её запуск внутри Астролябии; сборка склеивает их в одну область `IZ`;
  - `elv.js` — тексты слоёв Земли, Биосферы и Абсолюта; `data.json` — станции, центры, оболочки, этапы;
  - `ref/out/` — подготовленные изображения анатомии и тела; `ref/*.py` — скрипты их подготовки;
  - `build2.py` — сборка.

## Сборка
```bash
cd src
npm install          # three@0.128.0 — копируется в dist/vendor
python3 build2.py    # пересобирает ../dist (а также astrolabia.html и preview.html для проверки)
```
